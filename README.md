# grbl_BlackPill — grblHAL для CNC 3018 на STM32F401 BlackPill

Прошивка [grblHAL](https://github.com/grblHAL/core) для настольного фрезера
CNC 3018 на плате **WeAct Studio BlackPill STM32F401CCU6 / STM32F401CEU6**.
Драйвер платы написан **только на регистрах и CMSIS** (без HAL / LL / Cube),
проект — для **IAR Embedded Workbench for ARM**. За основу взяты структура,
CMSIS, тактирование, USB CDC и проект IAR из
[Teacup_Firmware_iar](https://github.com/alexsys87/Teacup_Firmware_iar);
ядро grblHAL используется без изменений.

В каталоге [`host`](host/README.md) — программа управления станком для
Windows (WPF, .NET 8), переделанная из Teacup Host.

## Что есть

- ядро grblHAL (`grbl/`, версия в `grbl/CORE_VERSION.txt`) без изменений;
- 3 оси, шаговые импульсы по таймеру TIM5 (32 бит, 21 МГц), импульс
  4 мкс, задержка импульса после смены направления (`$29`);
- шпиндель: ШИМ на TIM1_CH1 (PA8, 1 кГц, 0…10000 об/мин), включение,
  направление (M3 / M4 / M5), тот же выход годится для лазера;
- СОЖ: M8 (охлаждение) и M7 (туман);
- концевики X / Y / Z, щуп (G38.2…G38.5), кнопки сброса, паузы, старта,
  датчик двери — на прерываниях EXTI с антидребезгом;
- связь с компьютером: **USB CDC** (виртуальный COM-порт на разъёме платы,
  по умолчанию) или **USART1** 115200;
- настройки (`$$`), смещения и стартовые строки хранятся во **flash**
  (сектор 1, 16 КБ по адресу 0x08004000);
- команда **`$DFU`** — перезапуск в системный загрузчик STM32 для прошивки
  по USB без нажатия кнопки BOOT0;
- 84 МГц от кварца 25 МГц (если кварц не запустился — от HSI);
- светодиод PC13 горит, когда контроллер работает.

Размер: ~174 КБ flash, ~29 КБ ОЗУ — помещается в STM32F401CC (256 / 64 КБ).

## Подключение

| Сигнал | Вывод | Примечание |
|--------|-------|------------|
| X STEP / DIR | PA0 / PA1 | к драйверам (A4988, DRV8825, TMC2208 …) |
| Y STEP / DIR | PA2 / PA3 | |
| Z STEP / DIR | PA4 / PA5 | |
| ENABLE драйверов | PB0 | активный низкий (`$4`) |
| Концевик X / Y / Z | PB12 / PB13 / PB14 | НО контакт на GND, внутренняя подтяжка |
| Щуп | PB15 | пластина на GND, крокодил на фрезе |
| Сброс | PB6 | кнопка на GND |
| Пауза (feed hold) | PB7 | кнопка на GND |
| Старт (cycle start) | PB8 | кнопка на GND |
| Дверь | PB9 | по умолчанию выключена |
| Шпиндель ШИМ | PA8 | TIM1_CH1, на MOSFET-модуль шпинделя / лазер |
| Шпиндель вкл. | PB1 | |
| Шпиндель направление | PB2 | |
| СОЖ охлаждение (M8) | PB4 | |
| СОЖ туман (M7) | PB5 | |
| USART1 TX / RX | PA9 / PA10 | если `USB_SERIAL_CDC 0` |
| USB | PA11 / PA12 | разъём USB-C платы |
| Светодиод | PC13 | |

Выходы платы — 3,3 В: большинство драйверов шаговых двигателей и
MOSFET-модулей их понимают; для входов 5 В-логики нужен преобразователь
уровней. Входы рассчитаны на контакты на землю (внутренняя подтяжка), это
задают маски инверсии по умолчанию (`$5=7`, `$14`, `$6=1`).

Карта выводов — [`driver/boards/cnc3018_blackpill_map.h`](driver/boards/cnc3018_blackpill_map.h),
опции сборки — [`driver/my_machine.h`](driver/my_machine.h).

## Настройки по умолчанию

Задаются в [`driver/cnc3018_defaults.h`](driver/cnc3018_defaults.h) (подключается
ко всем файлам опцией «Preinclude» компилятора) и применяются при первом
запуске или по `$RST=$`:

| Параметр | Значение |
|----------|----------|
| `$100…$102` шаги на мм | 800 (винт T8 шаг 2 мм, 1/8 микрошага) |
| `$110…$112` макс. скорость | 1000 / 1000 / 600 мм/мин |
| `$120…$122` ускорение | 50 мм/с² |
| `$130…$132` ход | 300 / 180 / 45 мм |
| `$0` импульс шага | 4 мкс |
| `$30` / `$31` обороты | 10000 / 0 |
| `$33` частота ШИМ | 1000 Гц |
| `$22` / `$21` / `$20` | поиск нуля, жёсткие и программные пределы выключены |

У стандартного 3018 нет концевиков: если они установлены, включите
`$21=1` (жёсткие пределы), `$22=1` (поиск нуля), `$23` (направление поиска)
и `$20=1` (программные пределы).

## Сборка в IAR EWARM

1. IAR Embedded Workbench for ARM 9.x.
2. Откройте `ewarm/grbl_BlackPill.eww`. В нём два проекта:
   `grbl_STM32F401CC` (256 КБ flash) и `grbl_STM32F401CE` (512 КБ) — выберите
   по маркировке чипа на плате.
3. Конфигурации `Debug` (оптимизация Medium) и `Release` (High, по размеру).
4. Make (F7). Результат — `ewarm/<конфигурация>/<чип>/Exe/grbl_<чип>.out` и `.bin`.

В проектах уже заданы: определения `STM32F401xC` / `STM32F401xE`, пути
`$PROJ_DIR$\..`, `cmsis\core`, `cmsis\device`, `driver`, Preinclude
`driver\cnc3018_defaults.h`, линкер-файлы `cmsis/linker/stm32f401x?_flash.icf`
(сектор 1 flash исключён из кода — там настройки), startup из
`cmsis/startup`, `char` без знака, расширения языка IAR включены.

Файлы проектов генерирует `tools/make_ewarm.py` из шаблона, сохранённого в
IAR (`tools/ewarm_template.ewp/.ewd`). После добавления или удаления
исходников запустите `python3 tools/make_ewarm.py`.

Отладка — ST-Link (SWD: PA13 / PA14) прямо из IAR.

## Сборка GCC (проверка и тесты)

Для проверки без IAR есть Makefile на `arm-none-eabi-gcc`:

```
cd test/gcc
make                 # STM32F401CC, связь по USB CDC  → build_F401C_0/grbl.elf, .bin
make CHIP=F401E      # STM32F401CE
make TEST=1          # связь по USART1 (для эмулятора)
```

## Прошивка

- **USB DFU**: зажмите BOOT0, нажмите NRST, отпустите BOOT0 (или отправьте
  `$DFU` уже прошитой плате), затем прошейте `.hex` программой
  STM32CubeProgrammer (USB) — настройки в секторе 1 сохранятся. Можно и
  `dfu-util -a 0 -s 0x08000000:leave -D grbl.bin`, но `.bin` покрывает и
  сектор настроек: после такой прошивки они вернутся к значениям по умолчанию.
- **ST-Link**: из IAR (Download and Debug) или STM32CubeProgrammer (SWD).

После прошивки плата появляется как виртуальный COM-порт (драйвер в
Windows 10/11 встроенный). Скорость порта значения не имеет.

## Тесты в эмуляторе Renode

`test/renode/run_tests.py` запускает прошивку в [Renode](https://renode.io)
(модель STM32F401 с USB OTG FS из проекта Teacup) и проверяет по протоколу
grbl: приветствие и `$I`, `$$`, блокировку после ошибки и Ctrl-X, число
шаговых импульсов (800 на мм), направление, дугу G2, паузу и продолжение,
отмену перемещения, ШИМ шпинделя M3 / M4 / M5, СОЖ M7 / M8 / M9, запись
настройки во flash и её сохранение после перезагрузки, тревогу по концевику,
щуп `[PRB:]`, кнопку паузы.

```
cd test/gcc && make TEST=1 && make
python3 test/renode/run_tests.py                  # через USART1
GRBL_PORT=usb python3 test/renode/run_tests.py    # через USB CDC
```

## Структура

| Каталог | Содержимое |
|---------|------------|
| `grbl/` | ядро grblHAL (без изменений) |
| `driver/` | драйвер платы на регистрах: `driver.c` (шаги, входы, EXTI, таймеры), `spindle.c` (ШИМ TIM1), `serial.c` (USART1), `usb_cdc.c` (USB OTG FS CDC), `nvs_flash.c` (настройки во flash), `ioports_aux.c` (дополнительные входы / выходы), `cpu.c` (тактирование, DFU), `main.c` |
| `driver/boards/` | карта выводов |
| `cmsis/` | CMSIS Core, файлы устройства STM32F401, startup и линкер-файлы IAR |
| `ewarm/` | проекты IAR EWARM |
| `tools/` | генератор проектов IAR |
| `test/gcc/` | Makefile, startup и линкер-файл для GCC |
| `test/renode/` | платформа и тесты Renode |
| `host/` | программа управления станком Grbl Host (WPF, .NET 8) |
